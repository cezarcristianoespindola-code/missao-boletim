# Missão Boletim

Jogo para alunos acompanharem as notas dos trimestres: simulador do 3º trimestre, evolução por matéria, níveis e medalhas.

Tudo roda no navegador. O PDF do boletim é lido no próprio aparelho e as notas ficam salvas só nele (localStorage). Não há servidor, cadastro ou coleta de dados.

Acesse: https://cezarcristianoespindola-code.github.io/missao-boletim/
